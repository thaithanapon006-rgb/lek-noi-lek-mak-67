# เลขน้อย เลขมาก ก็ 67

เว็บไซต์เกมการเรียนรู้คณิตศาสตร์สำหรับเด็กประถมศึกษา แต่ละบทมี Flow ครบ:
**Pre-test → สรุปคะแนนก่อนเรียน → วิดีโอ → ใบงานทบทวน → ตรวจทานคำตอบ → Post-test → บันทึกผล → ปลดล็อกบทถัดไป**

## เว็บไซต์นี้ทำงานอย่างไร

- เปิดไฟล์ `index.html` แล้วเล่นได้เลย ไม่ต้องติดตั้งอะไรเพิ่ม (Static Site ล้วน)
- **ไม่เก็บชื่อจริง-นามสกุลของเด็ก** — เก็บแค่ **ชื่อเล่น** ที่เด็กตั้งเอง + **รหัส 6 หลัก** ที่ระบบสุ่มสร้างให้อัตโนมัติ (ไม่ใช่ข้อมูลที่ระบุตัวตนได้จริง)
- ทำงานได้ 2 โหมดโดยอัตโนมัติ ไม่ต้องแก้โค้ด:
  - **Local Mode** (ค่าเริ่มต้น) — ยังไม่ได้ตั้งค่า Firebase เก็บ Progress ไว้ใน `localStorage` ของเบราว์เซอร์เครื่องนี้เท่านั้น ใช้งานได้ครบทุกฟีเจอร์ทันที เหมาะสำหรับทดสอบ
  - **Cloud Mode** — เมื่อกรอก `js/firebase-config.js` ครบแล้ว จะเชื่อมต่อ Firebase Realtime Database ให้อัตโนมัติ ทำให้กลับมาดู Progress จากอุปกรณ์ไหนก็ได้ด้วยรหัสเดิม

## โครงสร้างไฟล์

```
index.html            หน้าเว็บหลัก (ทุกหน้าจอ)
css/
  style.css            ดีไซน์หลัก สี ฟอนต์ เลย์เอาต์ (รวมหน้าใหม่ทั้งหมด)
  animations.css        แอนิเมชันตัวละคร 67 (เวอร์ชันดั้งเดิม)
  mascot67.css           สไตล์มาสคอตเวอร์ชัน Chibi (ปิดใช้งานอยู่ ไม่ได้ลิงก์ใน index.html)
js/
  lessons.js            ข้อมูลบทเรียนทั้งหมด + PASS_SCORE (แก้ตรงนี้เพื่อเพิ่ม/แก้บท)
  scoring.js             ระบบคำนวณคะแนนและดาว (ไม่ถูกแก้)
  games.js               เอนจินคำถามแบบเลือกตอบ ใช้ซ้ำกับ Pre-test/ใบงาน/Post-test ทั้งหมด
  youtube.js              ควบคุมวิดีโอ YouTube (ล็อก Controls + ตรวจจับดูจบจริง)
  firebase-config.js       ใส่ค่าโปรเจกต์ Firebase ของคุณที่นี่ (ดูหัวข้อด้านล่าง)
  data-service.js          บันทึก/โหลด Progress (Firebase หรือ localStorage อัตโนมัติ)
  app.js                  ตัวควบคุมหน้าจอทั้งหมด + Course Flow
  mascot67.js              มาสคอตเวอร์ชัน Chibi (ไม่ได้ใช้งานอยู่ตอนนี้)
```

## บทเรียนทั้ง 6 บท

ทุกบทใช้โครงสร้างเดียวกัน (`type: "course"`) ใน `js/lessons.js`:

| บท | ชื่อ | ระดับ | สถานะ |
|---|---|---|---|
| 1 | ตะลุยเมืองจำนวน | 🟢 ง่ายมาก | ✅ มีวิดีโอ+คำถามครบ เปิดใช้งานได้ |
| 2 | รวมพลังและแยกพวก | 🟢 ง่าย | 🔒 รอวิดีโอ+คำถาม |
| 3 | ถอดรหัสลับตัวเลข | 🟡 เริ่มท้าทาย | 🔒 รอวิดีโอ+คำถาม |
| 4 | ชิ้นส่วนที่หายไป | 🟠 ปานกลาง | 🔒 รอวิดีโอ+คำถาม |
| 5 | ปริศนาตัวแปรล่องหน | 🔴 ยาก | 🔒 รอวิดีโอ+คำถาม |
| 6 | ยอดนักสืบตัวเลข | 🟣 ท้าทายมาก | 🔒 รอวิดีโอ+คำถาม |

บทที่ยังไม่มี `videoUrl`/คำถามจริง (`hasContent: false`) จะแสดงเป็น "🔒 เร็วๆ นี้" เสมอในหน้ารวมบทเรียน **ไม่ว่าจะผ่านบทก่อนหน้าแล้วหรือไม่** ตามที่กำหนดไว้ — เมื่อได้รับวิดีโอ + คำถาม 10 ข้อ (Pre/Post-test) + ทบทวน 3 ข้อของบทใด ให้เติมลงใน `preTest`/`review`/`postTest` ของบทนั้นแล้วเปลี่ยน `hasContent` เป็น `true`

**เกณฑ์ผ่านบท:** ตั้งไว้ที่ตัวแปร `PASS_SCORE` ในบรรทัดแรกๆ ของ `js/lessons.js` (ปัจจุบัน 6 จาก 10 ข้อ) แก้เลขนี้ที่เดียวเพื่อเปลี่ยนเกณฑ์ทั้งเว็บ

## การตั้งค่า Firebase (ไม่บังคับ — ไม่ตั้งก็ใช้งานได้ผ่าน Local Mode)

1. ไปที่ [Firebase Console](https://console.firebase.google.com) สร้างโปรเจกต์ใหม่ (ฟรี)
2. เปิดใช้งาน **Realtime Database** (Build > Realtime Database > Create Database)
3. ไปที่ Project settings > เลื่อนลงหา "Your apps" > กด "</>" เพื่อสร้าง Web App
4. คัดลอกค่าจาก `firebaseConfig` ที่ได้ ไปวางแทนที่ค่าใน `js/firebase-config.js`
5. ไปที่ **Authentication** > Sign-in method > เปิดใช้งาน **Anonymous** (จำเป็น เพราะ Security Rules ด้านล่างต้องการ `auth != null`)
6. ไปที่ Realtime Database > Rules แล้ววางกฎนี้แทนค่าเริ่มต้น:

```json
{
  "rules": {
    "users": {
      "$code": {
        ".read": "auth != null",
        ".write": "auth != null",
        ".validate": "newData.hasChildren(['nickname', 'createdAt', 'unlockedUpTo'])"
      }
    }
  }
}
```

**ข้อจำกัดด้านความปลอดภัยที่ควรทราบ:** ระบบรหัส 6 หลักแบบนี้ไม่ใช่การยืนยันตัวตนที่รัดกุม — Rules ด้านบนอนุญาตให้ผู้ใช้ที่ล็อกอินแบบ Anonymous คนไหนก็ได้ (ทุกคนที่เปิดเว็บนี้) อ่าน/เขียนข้อมูลของรหัสไหนก็ได้ถ้ารู้หรือเดารหัสถูก เหมาะสำหรับข้อมูลความเสี่ยงต่ำแบบนี้ (ไม่มีชื่อจริง ไม่มีข้อมูลอ่อนไหว) เท่านั้น **ไม่ควรใช้แพทเทิร์นนี้เก็บข้อมูลที่สำคัญกว่านี้** หากต้องการความปลอดภัยที่สูงขึ้น ควรใช้ Firebase Authentication แบบมีรหัสผ่านจริง หรือมีระบบ Backend ตรวจสอบสิทธิ์แยกต่างหาก

## วิธี Deploy ขึ้น GitHub Pages

1. เข้า [github.com](https://github.com) > สร้าง Repository ใหม่ (Public)
2. Add file > Upload files > ลากไฟล์/โฟลเดอร์ทั้งหมดขึ้นไป > Commit changes
3. Settings > Pages > Source เลือก "Deploy from a branch" > Branch เลือก `main` และ `/ (root)` > Save
4. รอ 1-2 นาที แล้วเปิดลิงก์ที่ปรากฏ (`https://ชื่อผู้ใช้.github.io/ชื่อ-repo/`)

## หมายเหตุด้าน Accessibility

- รองรับ `prefers-reduced-motion`
- ปุ่มสำคัญมี `aria-label` และใช้งานด้วยคีย์บอร์ดได้ (Tab + Enter บนการ์ดบทเรียน)
- Feedback เชิงบวกเสมอ ไม่ใช้คำว่า "ผิด/สอบตก/คะแนนน้อย" ไม่ว่าคะแนนจะเป็นเท่าไร
